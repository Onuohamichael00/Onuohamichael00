## Featured Projects

### Vertex Supply Chain Performance Analysis

A SQL-based supply chain analysis focused on supplier, product, warehouse, shipment, profitability, and transportation performance. Using MySQL, I analyzed inventory received, damaged goods, transportation costs, revenue, profitability, supplier performance, product performance, warehouse performance, and monthly trends.

The project involved business KPI calculations, multi-table joins, aggregate functions, subqueries, ranking functions, window functions, and business-oriented analysis to identify profitable and loss-making products and suppliers and provide recommendations for improving supply chain performance.

### FMCG Sales & Profitability Analysis

An end-to-end FMCG analytics project focused on sales performance, profitability, customer purchasing behavior, product performance, pricing, promotions, and inventory.

I used Excel, Power Query, Power Pivot, and DAX to clean and transform the data, build a structured data model, develop business KPIs, and create an interactive dashboard that helped identify sales trends, profitability drivers, product performance, and changes in customer purchasing behavior.

### Brazilian E-Commerce Analysis

An analysis of the Brazilian Olist e-commerce dataset involving customers, orders, products, payments, sellers, and delivery information across multiple related tables.

The project focuses on using Microsoft Excel, Power Pivot and data modelling techniques to explore sales performance, customer behavior, product performance, order activity, payments, and delivery trends.
